# Ajadi Keys — установка

1. Откройте [Releases](https://github.com/ajadi/AjadiKeys/releases), скачайте и установите основной APK.
2. Откройте Ajadi Keys → «Включить клавиатуру» → «Выбрать клавиатуру». После обновления Android иногда возвращает прежнюю клавиатуру: выберите Ajadi Keys снова.
3. В «Языки и словари» → «Языковые пакеты» скачайте нужные APK и установите штатным установщиком Android. Русский пакет 1.1.0 расширяет словарь; EN/HE 1.0.0 остаются совместимыми. Обычный ввод работает без пакетов.

## Управление

- «Ввод»: подсказки, автокоррекция, обучение, автозаглавная буква, Backspace и буфер. Свайп по Backspace влево удаляет слово, вправо восстанавливает последнее доступное удаление в обычном поле. Длительное удержание и тройной тап настраиваются отдельно.
- «Оформление»: высота, темы и прозрачность, цифровой ряд, компактный альбомный режим, глобус, расширенная компьютерная клавиатура. Компьютерный режим по умолчанию выключен. На достаточно широком экране с доступной высотой от 480 dp отображается полная компьютерная раскладка; на телефоне — компактная панель. Если обе кнопки включены, тап открывает компьютерную панель, удержание меняет язык.
- Свайп по пробелу меняет язык. Удержание #1? открывает настройки. Удержание буфера открывает недавние/сохранённые фразы. Удержание пробела открывает голосовой ввод при включённой функции.
- «Языки и словари»: личный словарь, сокращения, экспорт/импорт. Резервную копию выбирает пользователь; она содержит личное обучение, поэтому храните её локально.
- Эмодзи: категории, поиск RU/EN, контекстные предложения рядом со словами. Статистика использования только при включённом обучении.
- Кнопка ⇄ в обычном текстовом поле показывает варианты исправления раскладки текущего слова или выделения; выберите нужный результат.

В «Голос» и «Перевод» скачайте APK движка (для обычных современных ARM64-телефонов — arm64-v8a), установите его через Android, скачайте ZIP модели и импортируйте в соответствующем разделе. Уже импортированные модели повторно скачивать не нужно. Микрофон нужен только для голосового ввода. В настройках можно удалить компоненты и модели отдельно.
ИИ — отдельное необязательное приложение, сервис и ключ настраиваются пользователем. Передача только после явного подтверждения выбранного текста; основной IME не имеет INTERNET.

Статусы пакетов и движков отражают установку, доступность и локально известную версию. Проверка новых версий — в браузере по кнопке.
